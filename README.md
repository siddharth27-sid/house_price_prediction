# House Price Prediction

##  About the Project

This project uses machine learning to predict house prices based on different features such as crime rate, number of rooms, property tax, distance to employment areas, and other housing-related factors.

##  Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

##  Machine Learning Models

The following regression models are used in this project:

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

##  Project Steps

1. Load the dataset
2. Explore and understand the data
3. Check for missing values
4. Analyze correlations between features
5. Visualize the data
6. Split the data into training and testing sets
7. Train machine learning models
8. Evaluate model performance
9. Compare the models

##  Evaluation Metrics

The models are evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

##  How to Run

Install the required Python libraries:

```bash
pip install -r requirements.txt
```

Run the Python program:

```bash
python house_price.py
```

##  Project Files

- `house_price.py` — Python source code
- `requirements.txt` — Required Python libraries
- `House Price Prediction Dataset.csv` — Dataset
- `README.md` — Project documentation

##  Objective

The main objective of this project is to understand and apply machine learning regression techniques for house price prediction.
